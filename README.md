# Omnia Hamada — Personal Portfolio

A responsive personal portfolio built with HTML, CSS, and Bootstrap 5.

## Files
- `index.html` — page content and Bootstrap layout
- `style.css` — custom colors, spacing, and responsive styling

## Before submitting
1. Replace the sample email and GitHub username in `index.html`.
2. Update the education details and skills so they accurately describe you.
3. Replace the sample project descriptions with your real work when available.
4. Upload both files to a public GitHub repository.

## Publish with GitHub Pages
Open the repository's **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
